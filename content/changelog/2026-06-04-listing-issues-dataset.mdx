A new dataset surfaces Amazon's listing issues, compliance problems, catalog errors, and other flags from the Listings Items API, directly in Snowflake.

- [Customer documentation](/help-center/data-reference/product-data-reference#listing-issues-compliance--catalog-problems)

**New table:**

- `SELLING_PARTNER.LISTING_ITEMS`

<Callout type="info">
  This is a raw table today; a dedicated view or dashboard is planned to make it easier to filter and browse. Until then, see the linked documentation for a ready-to-use query.
</Callout>
